### ✨ Điểm nổi bật
- ✍️ **Chuẩn bút thuận:** Sai nét / ngược chiều là rung báo lỗi ngay.
- 🎁 **Viết là có quà:** Viết chữ *Ăn* có đùi gà 🍗, viết chữ *Trà* có nước ấm 🍵.
- 🗺️ **5 Trạm ngao du:** Bắc Kinh ➔ Tứ Xuyên ➔ Giang Nam ➔ Tuyết Sơn ➔ Võ Đang.
- 🔊 **Phát âm chuẩn:** Tích hợp đọc tiếng Trung và giải nghĩa tiếng Việt.
